# 💰 Système de Gestion Financière

Application desktop complète pour la gestion financière d'entreprise : ventes, clients, fournisseurs, stocks et facturation.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![SQLite](https://img.shields.io/badge/SQLite-Database-lightgrey.svg)
![Tkinter](https://img.shields.io/badge/Tkinter-GUI-orange.svg)

## ✨ Fonctionnalités

- 📦 **Gestion des articles** : Catalogue produits avec catégories et prix
- 👥 **Gestion des clients** : Base clients avec suivi des crédits et règlements
- 🏭 **Gestion des fournisseurs** : Relations fournisseurs et bons de commande
- 🧾 **Gestion des ventes** : Facturation et suivi des transactions
- 📊 **Rapports et listes** : Export et visualisation des données

## 🛠 Stack Technique

- **Langage** : Python 3.8+
- **Interface** : Tkinter avec ttkthemes
- **Base de données** : SQLite
- **PDF Generation** : ReportLab

## 📸 Aperçu

L'application propose une interface intuitive pour gérer tous les aspects financiers de votre entreprise.

## 🚀 Installation

```bash
# Cloner le repository
git clone https://github.com/medaziz701/projet-financier.git
cd projet-financier

# Installer les dépendances
pip install -r requirements.txt

# Lancer l'application
python main.py
```

## 📝 Mode Démonstration

Pour utiliser l'application avec des données fictives (idéal pour les présentations) :

```bash
# Activer le mode démo
echo "1" > demo_mode.txt
python main.py
```
